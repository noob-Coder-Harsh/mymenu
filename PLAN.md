Redesign the FoodBaba merchant home page as a live order-operations screen, not a traditional analytics dashboard. This screen will often remain open beside the counter during store operations, so the primary purpose is to let the merchant instantly see what needs attention without touching or navigating the device. Keep the existing backend, API, authentication, routing, and order logic intact and focus on the UI/UX and interaction model. The top should have a compact header with store name, open/closed status, notification indicator, and account access, followed by a very compact Today summary showing only essential numbers such as orders and sales; do not use large stat cards because they consume space needed for live orders, and make the summary expandable/tappable if more statistics are needed. The main content should be dynamically organized by operational priority: NEW orders first, then PREPARING, READY, and other active states, with the most urgent/action-required orders always visible at the top. Every order should use a compact but readable card showing order number, total amount, item count/time, and only the necessary item summary, with one obvious primary action based on its current status: NEW → Accept Order, ACCEPTED → Start Preparing, PREPARING → Mark Ready, READY → Complete/Hand Over. The merchant should be able to progress an order directly from the home screen without opening order details; swipe gestures can be supported as an optional enhancement, but buttons must remain the primary interaction because the target users may not be comfortable with gestures. When a new order arrives through realtime updates, immediately place it at the top of the NEW section, visually highlight it, and make the system ready for sound/browser notification so the merchant can notice it without watching the screen continuously; a new order should remain visible until acknowledged. Avoid large dashboard sections, charts, unnecessary customer information, long order cards, or duplicated navigation actions. If there are no active orders, show a calm "All caught up" empty state with the store status and today's compact summary. Keep the bottom navigation simple: Home, Orders, Menu, Store. Home should answer "What needs my attention right now?", while Orders is the full historical/search/filter management screen, Menu manages products/menu, and Store manages store settings. The overall visual design should remain consistent with the existing FoodBaba warm cream background and orange brand color, use strong status colors sparingly, rounded compact cards, clear typography, high contrast, generous touch targets, and a mobile-first layout. The screen should prioritize the workflow eyes → recognize → one tap → next order rather than read → navigate → open order → change status. Do not introduce unnecessary features or create a generic SaaS dashboard; build the MVP around fast, glanceable order operations for small Indian food businesses.
