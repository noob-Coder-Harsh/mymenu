Implement a **Counter Order** feature in the merchant app for quickly creating orders on behalf of walk-in customers who verbally place orders at the counter, without creating a separate primary screen or disrupting the existing live order operations flow. Add a prominent **“+ Counter Order”** action on the merchant Home/live-order screen; tapping it should open a large bottom sheet containing item search, category filters, and a compact, fast-tapping product list without large product images, allowing the merchant to quickly add items and adjust quantities/variants where applicable. After selecting items, provide a lightweight order review showing items, quantities, prices, total amount, and payment method selection with **Cash as the default**, followed by a **“Create Order”** action. On successful creation, generate the order using the existing order system/API and mark it with `order_source = counter`, then show a brief success confirmation with the order number and amount and return the merchant directly to the live Home screen. Counter orders should appear alongside QR/customer orders while clearly indicating their source, but the existing backend, authentication, routing, order logic, database structure, and existing QR ordering flow must remain intact unless a minimal change is required to support the new `counter` order source. The primary UX goal is to let a merchant handle a verbal order such as “one caramel coffee and two momos” in only a few taps and return immediately to monitoring incoming orders; optimize the entire flow for speed, mobile/touch use, small food businesses, and minimal navigation, while keeping a full-screen menu/order experience only as an optional secondary escape hatch if the catalog is large.
